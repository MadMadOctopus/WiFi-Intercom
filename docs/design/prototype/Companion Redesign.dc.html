Group and device IDs
A group is an intercom channel, not a radio network. Every device and companion that should hear each other must carry the same group ID on the same 2.4 GHz LAN. A group holds up to 16 devices.
Current group MESH · 16 devices, 1 companion This companion's ID a9d5b153 · generated once, unique on this PC
Change the group ID
This breaks the intercom until every node carries the new ID.
· Devices still on MESH disappear from this companion and can no longer hear it.
· Each device must be changed separately, over USB or with a configuration write, and each one reboots.
· A device you cannot reach right now keeps the old group until you get to it physically.
· Two groups on the same LAN never mix, so a half-finished change leaves two isolated intercoms.
New group ID
exactly 4 characters, A–Z and 0–9

Device IDs
A device ID identifies one unit inside the group and must be unique. Change it from that device's Configure dialog; the companion refuses an ID already held by another device it can see.
